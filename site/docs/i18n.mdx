# Localization (i18n)

Every built-in string in the library — picker headlines and buttons, the
Snackbar dismiss button, the Badge announcement, Chip "Remove …", sheet and
dialog close buttons, and so on — is English by default and can be replaced
in two ways:

- **Per instance**, with the component's `*Label` / `get*Label` props
  (`<Snackbar dismissLabel="閉じる" />`).
- **For the whole app** (or a subtree), with `LocaleProvider`. It also sets
  the default `locale` of the date and time pickers.

A prop on a component always wins over the provider.

## LocaleProvider

```tsx
import { LocaleProvider, ThemeProvider } from 'm3-expressive-react'
import { ja } from './i18n/ja' // your translations (see below)

export function App() {
  return (
    <ThemeProvider seedColor="#6750A4">
      <LocaleProvider locale="ja-JP" labels={ja}>
        {/* … */}
      </LocaleProvider>
    </ThemeProvider>
  )
}
```

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `locale` | `string` (BCP 47) | `'en-US'` | Default `locale` of `DatePicker`, `DatePickerField` and `TimePicker`: month / weekday names, the first day of the week, the typed-date field order and the TimePicker's hour cycle. |
| `ampm` | `boolean` | from `locale` | Default `ampm` of every `TimePicker`: `true` = 12-hour clock with AM / PM, `false` = 24-hour. |
| `labels` | `LocaleLabels` | `{}` | Built-in strings per component — see [the keys](#label-keys). |

`useLocale()` returns the settings in effect — `{ locale, ampm, labels }` —
so your own formatting can use the same locale:

```tsx
const { locale } = useLocale()
const text = new Intl.DateTimeFormat(locale, { dateStyle: 'medium' }).format(date)
```

`LocaleProvider` is also a subpath entry: `import LocaleProvider from 'm3-expressive-react/LocaleProvider'`.

:::note Next.js App Router
`LocaleProvider` is a client component. A Server Component can render it
with `locale` / `ampm` and string labels, but **functions** (`getLabel`,
`getHourLabel`, …) cannot cross the server → client boundary. Put the
provider and your translations in your own `'use client'` module:

```tsx
// app/locale-provider.tsx
'use client'
import { LocaleProvider } from 'm3-expressive-react'
import { ja } from './i18n/ja'

export function AppLocaleProvider({ children }: { children: React.ReactNode }) {
  return <LocaleProvider locale="ja-JP" labels={ja}>{children}</LocaleProvider>
}
```
:::

### Precedence

1. The component's own prop (`dismissLabel`, `locale`, `ampm`, …)
2. The nearest `LocaleProvider`
3. An outer `LocaleProvider` — a nested provider overrides single keys and
   inherits everything else
4. The English default (`'en-US'`)

```tsx
<LocaleProvider locale="ja-JP" labels={ja}>
  {/* Only this subtree reads "翌月" for the next-month button. */}
  <LocaleProvider labels={{ DatePicker: { nextMonthLabel: '翌月' } }}>
    <DatePicker />
  </LocaleProvider>
</LocaleProvider>
```

### Locale, week start and the 24-hour clock

From `locale` the pickers derive, with the platform's `Intl` data:

- **Month and weekday names** and the headline date format.
- **The first day of the week** — `Intl.Locale(locale).getWeekInfo()` (or
  `weekInfo`) where the browser supports it, else Sunday. A Unicode
  extension such as `en-US-u-fw-mon` changes it where supported.
- **The typed-date field order and the helper text** of the date input
  (`MM/DD/YYYY` for `en-US`, `YYYY/MM/DD` for `ja-JP`).
- **The TimePicker's hour cycle** — `Intl.DateTimeFormat(locale, { hour:
  'numeric' }).resolvedOptions().hourCycle` (`ja-JP`, `en-GB`, `de-DE` →
  24-hour). MD3 sets the 24-hour preference outside the time picker,
  typically from system settings; pass `ampm` to follow your app's setting.

The library never reads `navigator.language`: without a provider, server
and client render the same `en-US` output. To follow the browser, pass the
language you resolved yourself (e.g. from the `Accept-Language` header on
the server) to `locale`.

## Label keys

`labels` is keyed by component name. Each key is the component prop of the
same name — same type, same English default (see each component's props
table) — except the provider-only keys marked below.

| Component | Keys |
| --- | --- |
| `DatePicker` | `titleLabel`, `noSelectionLabel`, `previousMonthLabel`, `nextMonthLabel`, `selectYearLabel`, `todayLabel`, `startDateLabel`, `endDateLabel`, `inRangeLabel`, `inputLabel`, `switchToInputLabel`, `switchToCalendarLabel`, `getErrorLabel`, `okLabel`, `cancelLabel`; provider-only: `rangeTitleLabel` (`'Select dates'`), `rangeInputTitleLabel` (`'Enter dates'`), `inputNoSelectionLabel` (`'Entered date'`) |
| `DatePickerField` | `label`, `openCalendarLabel`, `dialogLabel`, `getErrorLabel`, `previousMonthLabel`, `nextMonthLabel`, `previousYearLabel`, `nextYearLabel`, `selectMonthLabel`, `selectYearLabel`, `todayLabel` |
| `TimePicker` | `titleLabel`, `hourLabel`, `minuteLabel`, `selectHourLabel`, `selectMinuteLabel`, `periodLabel`, `amLabel`, `pmLabel`, `switchToInputLabel`, `switchToDialLabel`, `switchToScrollLabel`, `getHourLabel`, `getMinuteLabel`, `getErrorLabel`, `okLabel`, `cancelLabel`; provider-only: `inputTitleLabel` (`'Enter time'`) |
| `Badge` | provider-only: `getLabel(count)` — also used for the badges of `NavigationBarItem`, `NavigationRailItem` and `Tab` |
| `Snackbar` | `dismissLabel` (also the dismiss button of `SnackbarProvider` snackbars) |
| `SearchBar` | `backLabel`, `suggestionsLabel`, `placeholder` |
| `Chip` | `getRemoveLabel` |
| `Dialog` | `closeLabel`; provider-only: `fallbackLabel` (`'Dialog'`) |
| `BottomSheet` | `dragHandleLabel` (`'Close'`); provider-only: `partialDragHandleLabel` (`'Drag handle'`), `fallbackLabel` (`'Bottom sheet'`) |
| `SideSheet` | `closeLabel`, `backLabel`; provider-only: `fallbackLabel` (`'Side sheet'`) |
| `NavigationDrawer` | provider-only: `fallbackLabel` (`'Navigation'`) |
| `NavigationRail` | `modalLabel` |
| `Carousel` | `getItemLabel`, `roleDescriptionLabel`, `itemRoleDescriptionLabel` |
| `Slider` | `rangeStartLabel`, `rangeEndLabel` |
| `SplitButton` | `trailingAriaLabel` |
| `Autocomplete` | `toggleLabel` |
| `TextField` | `getCounterLabel` |
| `PullToRefresh` | `refreshingLabel` |

- **Per-mode headlines.** Where a component shows a different built-in
  string per mode, each mode has its own provider key (as Compose has one
  string resource each): `DatePicker` `titleLabel` is the single-date title,
  `rangeTitleLabel` / `rangeInputTitleLabel` the range titles; `TimePicker`
  `titleLabel` is the dial / scroll headline, `inputTitleLabel` the input
  one; `BottomSheet` `dragHandleLabel` names the closing handle,
  `partialDragHandleLabel` the expand / collapse one. The **props** of the
  same name still apply to every mode.
- **`fallbackLabel`** is the accessible name used only when the dialog /
  sheet / drawer has no title, `aria-label` or `aria-labelledby`.
- Not covered: strings the app always provides (e.g. `FabMenu` `ariaLabel`),
  and the DatePickerField helper text, which shows the locale's input
  pattern (`MM/DD/YYYY`) — set `supportingText` to replace it.
