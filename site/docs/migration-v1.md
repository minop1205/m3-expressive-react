# Migrating to v1

The complete v1 breaking-change guide — event-first `onChange`,
`startIcon`/`endIcon`, the `xs–xl` size scale, `SegmentedButton` (singular),
the SearchBar `open` family, FAB `color`+`tonal`, and root refs with
`inputRef`/`inputProps` — lives in the repository:

**[docs/migration-v1.md on GitHub](https://github.com/minop1205/md3-react/blob/develop/docs/migration-v1.md)**

It includes before/after tables for every component and a checklist ordered
so the TypeScript compiler catches most of the work for you.
