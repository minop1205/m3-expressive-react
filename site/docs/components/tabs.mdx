# Tabs

MD3 tabs: a `role="tablist"` row of `Tab`s with a sliding active indicator,
in **primary** and **secondary** variants, fixed or scrollable.

## Variants

`primary` tabs sit at the top of a content pane under an app bar and use a
content-width indicator; `secondary` tabs divide content within a pane and
use a full-width line.

## Scrollable

Fixed tabs (default) split the row into equal widths. `scrollable` tabs size
to their content and scroll horizontally; the selected tab is scrolled to
the center whenever the selection changes.

<Demo>
  <div style={{ width: '100%', maxWidth: 480 }}>
    <Tabs aria-label="Categories" scrollable defaultValue="c1">
      {['News', 'Sports', 'Technology', 'Entertainment', 'Science', 'Health', 'Travel', 'Business'].map((l, i) => (
        <Tab key={l} value={`c${i + 1}`} label={l} />
      ))}
    </Tabs>
  </div>
</Demo>

```tsx
<Tabs scrollable value={value} onChange={(event, next) => setValue(next)}>…</Tabs>
```

## With panels

Tabs are controlled (`value` + `onChange`) or uncontrolled (`defaultValue`).
There is no panel component — render the panel yourself and link it with
`id` / `aria-controls` / `aria-labelledby`.

export function PanelDemo() {
  const [value, setValue] = useState('flights')
  const tabs = [
    ['flights', 'Flights', 'Search one-way and round-trip flights.'],
    ['hotels', 'Hotels', 'Find a place to stay.'],
    ['explore', 'Explore', 'Discover things to do nearby.'],
  ]
  const current = tabs.find(([v]) => v === value)
  return (
    <div style={{ width: '100%' }}>
      <Tabs aria-label="Trip planner" value={value} onChange={(_event, v) => setValue(v)}>
        {tabs.map(([v, label]) => (
          <Tab key={v} value={v} label={label} id={`tab-${v}`} aria-controls="trip-panel" />
        ))}
      </Tabs>
      <div role="tabpanel" id="trip-panel" aria-labelledby={`tab-${value}`} tabIndex={0} style={{ padding: 16 }}>
        {current[2]}
      </div>
    </div>
  )
}

## Accessibility

- `role="tablist"` of `role="tab"` buttons with `aria-selected`; label the
  list with `aria-label` and link panels via `aria-controls`.
- **Manual activation** (WAI-ARIA APG): <kbd>←</kbd> / <kbd>→</kbd>
  (mirrored in RTL), <kbd>Home</kbd> and <kbd>End</kbd> move focus only;
  <kbd>Space</kbd> / <kbd>Enter</kbd> select the focused tab and fire
  `onChange`. Arrow keys never fire `onChange`.
- Roving tabindex: <kbd>Tab</kbd> enters the list on the selected tab and
  leaves it in one step.
