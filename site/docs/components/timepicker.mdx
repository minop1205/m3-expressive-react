# TimePicker

MD3 time picker with a clock dial, a keyboard input mode and Expressive
scroll wheels, shown inline or as a modal dialog, in 12-hour (AM/PM) or
24-hour format, in the standard or vibrant style.

export const formatTime = (t) =>
  t ? `${String(t.hour).padStart(2, '0')}:${String(t.minute).padStart(2, '0')}` : '—'

## Dial

The value is a `TimeValue` — `{ hour, minute }` with `hour` always in
24-hour form (0–23). `onChange(value)` is value-first. Use `value` for a
controlled picker or `defaultValue` (default `{ hour: 12, minute: 0 }`) for
an uncontrolled one. Picking an hour on the dial with a pointer switches to
minutes.

export function DialTimePickerDemo() {
  const [time, setTime] = useState({ hour: 9, minute: 30 })
  return (
    <div>
      <TimePicker value={time} onChange={setTime} />
      <p style={{ margin: '12px 0 0' }}>Selected: {formatTime(time)}</p>
    </div>
  )
}

## Input mode

The keyboard / clock toggle switches between the dial and text input.
Start in input mode with `defaultMode="input"`, control it with `mode` +
`onModeChange`, or hide the toggle with `showModeToggle={false}`. Input is
validated (two digits, in range): invalid text shows an error and is never
reported through `onChange`.

<Demo>
  <TimePicker defaultMode="input" defaultValue={{ hour: 14, minute: 15 }} />
</Demo>

```tsx
<TimePicker defaultMode="input" defaultValue={{ hour: 14, minute: 15 }} />
```

:::note
Passing `mode` without `onModeChange` is deprecated: it only sets the
initial mode (v1.0 behavior). Use `defaultMode` for that; in v2 `mode` will
always be controlled.
:::

## 24-hour clock

`ampm={false}` shows a 24-hour dial (an inner 12–23 ring) without AM/PM.
When `ampm` is omitted it follows [`LocaleProvider`](/i18n) `ampm`, else the
`locale`'s hour cycle (default `'en-US'`, 12-hour), so `locale="ja-JP"` or
`"de-DE"` gives a 24-hour clock. MD3 sets the 24-hour preference outside the
time picker (typically in system settings) — `LocaleProvider ampm` is the
place for your app's setting.

<Demo>
  <TimePicker ampm={false} defaultValue={{ hour: 18, minute: 45 }} />
  <TimePicker locale="de-DE" defaultMode="input" defaultValue={{ hour: 18, minute: 45 }} />
</Demo>

```tsx
<TimePicker ampm={false} />
<TimePicker locale="de-DE" />
```

## Scroll wheels

`mode="scroll"` shows two endless scroll wheels (Compose's `TimeScroll`,
built on [ScrollField](/components/scrollfield)) instead of the dial. Scroll
with the mouse wheel, drag, or use ArrowUp / ArrowDown. The toggle then
switches between scroll and text input.

<Demo>
  <TimePicker defaultMode="scroll" defaultValue={{ hour: 7, minute: 45 }} />
</Demo>

```tsx
<TimePicker defaultMode="scroll" defaultValue={{ hour: 7, minute: 45 }} />
```

## Vibrant style

`variant="vibrant"` is the Expressive style (Compose's `vibrantColors()`,
`TimePickerShapes` and `VibrantTimePickerDialog`): a SurfaceContainer
container with 12px padding and no headline, larger 100×120
SurfaceContainerLowest time fields with a Primary selection, pill-shaped
AM / PM toggle buttons and a SurfaceContainerLowest dial. It applies to every
mode.

<Demo>
  <TimePicker variant="vibrant" defaultValue={{ hour: 9, minute: 30 }} onAccept={() => {}} />
  <TimePicker variant="vibrant" defaultMode="scroll" defaultValue={{ hour: 9, minute: 30 }} />
</Demo>

```tsx
<TimePicker variant="vibrant" onAccept={saveTime} />
<TimePicker variant="vibrant" defaultMode="scroll" />
```

## Horizontal layout

`orientation="horizontal"` (Compose's `TimePickerLayoutType.Horizontal`)
puts the time display and a wide AM / PM toggle beside the dial, for
landscape screens or short containers. It only changes the dial mode: the
input and scroll modes have a single layout.

<Demo>
  <TimePicker orientation="horizontal" defaultValue={{ hour: 16, minute: 20 }} />
</Demo>

```tsx
<TimePicker orientation="horizontal" />
```

## Modal dialog

Pass `open` to show the picker as a modal dialog (scrim, focus trap,
Escape) — the equivalent of Compose's `TimePickerDialog`; it renders
nothing while `false`. It adds the "Select time" headline and the
Cancel / OK row with draft / commit semantics: `onChange` reports the draft,
OK (or Enter in the minute field) calls `onAccept`, and Cancel, Escape, or a
scrim click reverts the value and calls `onCancel`. `onClose(reason)` asks
you to close, with `'accept' | 'cancel' | 'escapeKeyDown' | 'backdropClick'`.

export function ModalTimePickerDemo() {
  const [open, setOpen] = useState(false)
  const [draft, setDraft] = useState({ hour: 8, minute: 0 })
  const [saved, setSaved] = useState(null)
  return (
    <>
      <Button variant="filled" onClick={() => setOpen(true)}>
        Set alarm
      </Button>
      <span>Alarm: {formatTime(saved)}</span>
      <TimePicker
        open={open}
        onClose={() => setOpen(false)}
        value={draft}
        onChange={setDraft}
        onAccept={setSaved}
      />
    </>
  )
}

</Demo>

```tsx
const [draft, setDraft] = useState<TimeValue>({ hour: 8, minute: 0 })

  onAccept={(time) => saveAlarm(time)}

```

Passing `onAccept` or `onCancel` without `open` renders the headline and
action row on an inline picker.

:::warning Upgrading from 1.4 or earlier
Since 1.5.0 the modal TimePicker shows itself in the browser top layer (#494). If
your app wrapped it in its own popover or top-layer container (e.g. to lift
it above other layers), remove that wrapper: the app's layer would be painted
above the picker and block it.
:::

## Localization

Every built-in string is a prop with an English default: `titleLabel`,
`hourLabel`, `minuteLabel`, `amLabel`, `pmLabel`, `okLabel`, `cancelLabel`,
`switchToInputLabel`, `switchToDialLabel`, `switchToScrollLabel`, and the
`getHourLabel` / `getMinuteLabel` / `getErrorLabel` functions. Set them once
for the app with [`LocaleProvider`](/i18n) `labels.TimePicker` (the input-mode
headline has its own key there, `inputTitleLabel`).

## Accessibility

- The hour / minute selectors and AM / PM are radio groups (one Tab stop
  each; arrow keys move).
- The dial is a single Tab stop on the selected number: arrow keys move
  around the ring (continuing into the inner ring in 24-hour mode) and
  Enter / Space select. Numbers are read as "3 o'clock" / "15 minutes"
  (customize with `getHourLabel` / `getMinuteLabel`).
- In scroll mode the hour and minute wheels are spinbuttons ("Select hour"
  / "Select minutes", read as "7 o'clock" / "45 minutes"): ArrowUp / ArrowDown
  step and wrap, PageUp / PageDown move by 3 hours (6 on a 24-hour clock) or
  5 minutes, Home / End jump to the ends.
- The modal picker traps focus, closes on Escape, and returns focus to the
  opener.
