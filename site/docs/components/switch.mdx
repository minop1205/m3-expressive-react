# Switch

MD3 switch for turning a single setting on or off. Built on a native
`<input type="checkbox" role="switch">`, so labels, keyboard, and form
submission behave natively.

## Controlled

`selected` + `onChange` make the switch controlled; `onChange` receives the
native event and the next selected state. Use `defaultSelected` for an
uncontrolled switch.

export function ControlledSwitchDemo() {
  const [selected, setSelected] = useState(false)
  return (
    <label style={{ display: 'inline-flex', alignItems: 'center', gap: 12, cursor: 'pointer' }}>
      <Switch selected={selected} onChange={(event, next) => setSelected(next)} />
      Airplane mode ({selected ? 'on' : 'off'})
    </label>
  )
}

## Icons

`selectedIcon` is shown in the handle while the switch is on. Set `icons` to
show an icon in both states, with `unselectedIcon` for the off state. Icons
are any `ReactNode` — see [Icons](../icons.mdx).

<Demo>
  <Switch defaultSelected selectedIcon={<CheckIcon />} aria-label="Selected icon" />
  <Switch
    icons
    selectedIcon={<CheckIcon />}
    unselectedIcon={<CloseIcon />}
    aria-label="Icons in both states"
  />
</Demo>

```tsx
<Switch icons selectedIcon={<Check />} unselectedIcon={<Close />} aria-label="Notifications" />
```

## Accessibility

- The native input carries `role="switch"`: Tab focuses it and Space
  toggles it; the on state is exposed as checked.
- Provide an accessible name: wrap the switch in a `<label>` with visible
  text, or pass `aria-label`.
- The touch target is 48dp. `ref` points at the root element; `inputRef`
  reaches the native input.
