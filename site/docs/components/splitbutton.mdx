# SplitButton

MD3 Expressive split button: a leading action button joined to a trailing
button that opens a `Menu` of related actions. Opening the menu rounds the
trailing button's inner corner and flips its chevron.

## Variants

Both halves are styled by `Button`, so the variants and colors match it.

export const sendMenu = (
  <>
    <MenuItem startIcon={<EventIcon />}>Schedule send</MenuItem>
    <MenuItem startIcon={<EditIcon />}>Save as draft</MenuItem>
    <MenuItem startIcon={<DeleteIcon />}>Discard</MenuItem>
  </>
)

## Icons

`startIcon` adds a leading icon. An icon-only leading button (`startIcon`
without `children`) needs an `aria-label`, which is forwarded to the
leading button.

<Demo>
  <SplitButton startIcon={<SendIcon />} menu={sendMenu} trailingAriaLabel="More send options">Send</SplitButton>
  <SplitButton variant="tonal" startIcon={<SendIcon />} aria-label="Send" menu={sendMenu} trailingAriaLabel="More send options" />
</Demo>

```tsx
<SplitButton startIcon={<SendIcon />} aria-label="Send" menu={menu} />
```

## Controlled menu

The menu is uncontrolled by default (`defaultOpen`); pass `open` +
`onOpenChange(open)` to control it — here the state is mirrored in the
text beside the button.

export function ControlledDemo() {
  const [open, setOpen] = useState(false)
  return (
    <>
      <SplitButton
        open={open}
        onOpenChange={setOpen}
        menu={sendMenu}
        trailingAriaLabel="More send options"
      >
        Send
      </SplitButton>
      <span>Menu is {open ? 'open' : 'closed'}</span>
    </>
  )
}

<Demo>
  <ControlledDemo />
</Demo>

```tsx
const [open, setOpen] = useState(false)

<SplitButton open={open} onOpenChange={setOpen} menu={menu}>
  Send
</SplitButton>
```

## Menu alignment

`menuAlign` aligns the menu to the trailing button: `'end'` (default)
lines up the menu's end edge with it, `'start'` its start edge.

<Demo>
  <SplitButton variant="tonal" menuAlign="start" menu={sendMenu} trailingAriaLabel="More send options">Align start</SplitButton>
  <SplitButton variant="tonal" menuAlign="end" menu={sendMenu} trailingAriaLabel="More send options">Align end</SplitButton>
</Demo>

```tsx
<SplitButton menuAlign="start" menu={menu}>
  Send
</SplitButton>
```

## Accessibility

- Two native `<button>`s, each its own Tab stop. The `ref`, `onClick` and
  extra props land on the leading (action) button.
- The trailing button follows the APG menu-button pattern: it exposes
  `aria-haspopup` / `aria-expanded`; <kbd>Enter</kbd> / <kbd>Space</kbd> /
  <kbd>↓</kbd> open the menu on the first item (<kbd>↑</kbd>: the last),
  arrow keys cycle the items, <kbd>Escape</kbd> closes it and returns focus.
- The trailing button's name defaults to "More options"; prefer a
  `trailingAriaLabel` tied to the leading action, such as "More send
  options".
