# BottomSheet

MD3 bottom sheet: slides up from the bottom edge with 28dp top corners and
a drag handle. The default `modal` sheet sits over a scrim; scrim click,
<kbd>Escape</kbd>, or dragging the sheet down dismisses it. The `standard`
variant has no scrim and leaves the rest of the page usable.

      {/* Raised above the docs navbar; the sheet itself is position: fixed. */}

        <BottomSheet
          open={open}
          onClose={() => setOpen(false)}
          showDragHandle={showDragHandle}
          aria-label="Share"
          {...props}

            <List aria-label="Places">
              {places.map((place) => (
                <ListItem key={place} headline={place} supportingText="San Francisco, CA" />

            </List>

            <List aria-label="Share options">

              <ListItem headline="Share to contacts" onClick={() => setOpen(false)} />
            </List>

      </div>

  )
}

## Partially expanded and expanded

By default a sheet opens at full height and the drag handle dismisses it
(`skipPartiallyExpanded` defaults to `true`). Pass
`skipPartiallyExpanded={false}` to opt in to Compose's current detents: the
sheet opens **partially expanded**, showing half of its own height, at most
half of the screen (`SheetValue.PartiallyExpanded`). The drag handle then
toggles between partially expanded and **expanded** (full height) — with a
pointer, <kbd>Enter</kbd> or <kbd>Space</kbd> — and dragging snaps between
hidden, partial and expanded. Start expanded with `defaultExpanded`, or
control the detent with `expanded` / `onExpandedChange`. An uncontrolled
sheet reopens at its initial detent.

  onExpandedChange={setExpanded}
>

```

Opening partially expanded is Compose's default; it may become this
library's default in v2.

## Dragging

Drag the handle with a pointer. Releasing more than 56px from the starting
detent, or flinging faster than 125px/s, moves the sheet to the next detent
in that direction (Compose thresholds); otherwise it settles back. Without
the partial detent, that means a drag either dismisses or settles back. Reaching
the hidden position calls `onClose(event, 'drag')`. Hide the drag handle
with `showDragHandle={false}` — the sheet can still be closed by the scrim
and <kbd>Escape</kbd>.

</BottomSheet>
```

## Standard

`variant="standard"` co-exists with the page, like an audio player or map
details: no scrim, no focus trap, nothing is made `inert`, and body scroll
is not locked. It fills the bottom of its nearest positioned ancestor
(Compose `BottomSheetScaffold`), so place it inside a `position: relative`
container — or a `position: fixed` one to pin it to the viewport. It has
the same detents and drag behavior; the demo opts in to the partial detent.

## Accessibility

- The modal sheet is a `role="dialog"` with `aria-modal`; the standard sheet
  is a `role="region"` landmark. Name either with `aria-label` or
  `aria-labelledby` (default name: "Bottom sheet").
- While a modal sheet is open, focus moves into it and is trapped there, the
  rest of the page is `inert`, and body scroll is locked; on close, focus
  returns to the element that opened it. A standard sheet does none of
  this, and closes on <kbd>Escape</kbd> only while focus is inside it.
- The drag handle is a real button. By default it dismisses the sheet
  (default label "Close"); with `skipPartiallyExpanded={false}` it carries
  `aria-expanded` and toggles partially expanded / expanded (default label
  "Drag handle"). Relabel it with `dragHandleLabel`.
- Dragging is a pointer-only enhancement: every detent and dismissal is
  also reachable from the keyboard.
- With reduced motion, the sheet moves between detents instantly.
