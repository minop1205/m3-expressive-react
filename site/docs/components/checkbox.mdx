# Checkbox

MD3 checkbox with checked, indeterminate, and error states. Built on a
native `<input type="checkbox">` — label association, keyboard, and form
submission behave natively.

## States

<Demo>
  <Checkbox aria-label="Unchecked" />
  <Checkbox defaultChecked aria-label="Checked" />
  <Checkbox indeterminate aria-label="Indeterminate" />
  <Checkbox disabled aria-label="Disabled" />
  <Checkbox defaultChecked disabled aria-label="Disabled checked" />
</Demo>

```tsx
<Checkbox checked={checked} onChange={(event, next) => setChecked(next)} />
```

## Indeterminate

The mixed state is exposed to assistive technology via the native
`indeterminate` property and `aria-checked="mixed"`. An indeterminate
checkbox submits nothing on form submission, matching the platform.

<Demo>
  <Checkbox indeterminate aria-label="Parent" />
</Demo>
